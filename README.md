# カニ・クリーム・コロッケ Prototype 0.1

スマホ縦画面を主対象にした、3工程制バカゲーのプレイアブル試作です。

## 遊び方
`index.html` をブラウザで開いてください。GitHub Pages / Netlify Drop でもそのまま公開できます。

### 第1工程：カニ
- 岩陰から1体ずつ対象が現れます。
- 画面をタップするとその方向へ銛を突きます。
- 1個獲得した時点で終了。
- 空振りすると約1秒のクールタイム。
- 反応が速いほど「新鮮さ」が高くなります。
- 最大8候補。フェイントあり。

### 第2工程：クリーム
- 30秒間、ボウルを左右へドラッグします。
- 目標量は100。
- 最終的に全投入量の2/3以上を同じ液体が占めると、その液体として扱われます。
- 2/3未満なら「謎の液体」。
- 後半ほど落下密度が上がります。

### 第3工程：◯げる
- 「揚げる / 焦げる / 投げる / 逃げる / アげる」を目押し。
- 揚げる：通常のカリカリ度ゲージ。
- 焦げる：超高速・一方向の一発ゲージ。見切れば高評価可能。
- 投げる：投擲精度ゲージ。
- 逃げる：料理が逃走。
- アげる：DJイベント。

## スコア
- 新鮮さ、分量、仕上げの平均から「完成度倍率」を作成。
- 食材由来の基礎点 × 完成度倍率 + 芸術点。
- 料理図鑑は `localStorage` に保存されます。

## 次の検証ポイント
1. 第1工程の速度・フェイント率が理不尽すぎないか
2. 第2工程30秒が長すぎる/短すぎるか
3. 2/3判定と分量100の両立が面白いか
4. 焦げるの超高速ゲージが「無理」ではなく「上級者なら取れる」か
5. 第3工程の各オチが十分気持ちいいか
6. 専用イラストを入れる前に、ゲームテンポ自体が成立しているか


## Prototype 0.2 調整
- 第2工程を30秒→22秒に短縮
- 落下速度と出現密度を上昇
- ボウルの回収判定を「落下物の下端が口を通る瞬間」に修正
- 回収ラインを可視化
- ドラッグ位置計算を画面基準に修正
- 第3工程の「◯げる」ルーレットを遅く調整
- 揚げる／投げるの技能ゲージも少し遅く調整（焦げるは高難度のまま）


## v0.3 調整
- 第2工程の投射速度を v0.2 より少し遅くし、放物線を追いやすくした。
- 投射開始位置をプレイエリア上端よりさらに上へ移動。上部の主人公表示エリアの裏から材料が飛び込んでくるように見える。
- 投入口ラベルも画面上端へ移動。
